# mistery-trend-trading

> 蒸馏自《Mistery趋势交易论》（Mi 姐，约 540 页）的一套可执行的 A 股趋势交易决策框架。

把一本厚厚的趋势交易书读成"薄"的：先分类（情绪票/趋势票），再选股（三周期 + 顺大势逆小势），定系统（趋势交易系统 / 520 战法 / 5 日线主升法则），给信号（买卖点库），守风控（金字塔加仓、半仓滚动、破相思维），最后落宏观（流动性 + 产业周期 → 板块 → 个股的三级共振）。

底层信仰：**市场唯一不变的是变化本身，顺势而为，做趋势的跟随者而非预测者。**

## 方法论速览

1. **分类**：情绪票（快猛突变、击鼓传花）vs 趋势票（慢稳波段、基本面驱动）。
2. **选股**：三周期（大周期定方向 → 中周期选结构 → 小周期抓节奏）+ 顺大势逆小势。
3. **定系统**：趋势交易系统（5>20>60 多头）/ 520 战法（MA5×MA20）/ 5 日线主升法则。
4. **给信号**：回调 / 突破 / 形态 / 量价 / 指标 / 缠论买点，止盈止损 / 趋势反转卖点。
5. **守风控**：金字塔加仓、半仓滚动、永不被套、破相思维看穿诱多诱空。
6. **落宏观**：流动性 + 美元周期 + 产业周期 → 板块 → 个股的三级共振。
